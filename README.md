# GerMatch UI

The public Next.js frontend for the GerMatch matching platform. It is designed to work alongside `../ger-match-backend` and currently provides the marketing and onboarding entry experience.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:4002](http://localhost:4002).

## Verification

```bash
npm run lint
npm run build
```

Set `NEXT_PUBLIC_APP_URL` in a deployment environment to the canonical public URL.
